# TavaLead Vault

Shared workspace for Matthew and Timmy. Start here.

---

## Step 1 — Clone this vault to your computer

Open Terminal (Mac) or Command Prompt (Windows) and run:

```bash
git clone https://github.com/tavatrack/TavaLeadVault.git ~/Desktop/TavaLeadVault
```

This downloads everything to your Desktop.

---

## Step 2 — Open the How To folder

Once cloned, open the `TavaLeadVault` folder on your Desktop and read the guides in order:

```
How To/
├── 01 - What Is This Vault.md
├── 02 - First Time Setup.md
├── 03 - Daily Session Guide.md
├── 04 - How Claude Reads the Vault.md
└── 05 - Collaboration Rules.md
```

That's everything you need to get started.
